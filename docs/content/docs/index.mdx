# go-web-utils

一个轻量级、高性能的 Go Web 实用工具库，专注于解决 Web 开发中的常见需求。

## ✨ 特性

- 🚀 **高性能**: 零依赖，纯标准库实现
- 🛡️ **生产就绪**: 完整的测试覆盖和文档

## 📦 安装

```bash
go get github.com/woodchen-ink/go-web-utils
```

## 📚 文档导航

- [IP 工具包 (iputil)](./iputil/) - 客户端真实 IP 提取、可信代理模式、IP 校验与 CIDR 匹配
- [User-Agent 工具包 (uautil)](./uautil/) - 机器人/爬虫检测、浏览器检测、HTTP 中间件
- [统一响应 (resputil)](./resputil/) - 统一 JSON 响应结构，空数据永不返回 null
- [时区工具 (timex)](./timex/) - 业务时区显式初始化与自然日/周/月边界
- [Cookie 工具 (cookieutil)](./cookieutil/) - 安全默认值的认证 Cookie 与 CSRF 防护
- [定时任务工具 (cronutil)](./cronutil/) - 空轮退避、防重叠、去抖聚合队列
- [Next.js 静态托管 (nextstatic)](./nextstatic/) - export 产物托管、RSC 头处理、SEO 注入
